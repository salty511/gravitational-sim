# Solar System Simulation with Runge-Kutta and GPU Acceleration

This project simulates the motion of planets in the solar system using numerical integration. It compares CPU-based and GPU-accelerated implementations of the **Runge-Kutta 4th order (RK4)** algorithm to analyze performance and accuracy.

## Technologies Used

- Python
- NumPy & CuPy
- Matplotlib
- Astroquery & Astrop
